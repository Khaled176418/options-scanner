# ماسح الأسهم والعقود الأسبوعية

أداة تمسح السوق الأمريكي (S&P 500 وناسداك 100 وأسهم إضافية)، وتبحث عن أسهم مرشحة لحركة حادة، وترشّح لك عقد أسبوعي، وترسل التنبيه على تيليجرام. وفيها اختبار تاريخي يقيس نسبة نجاح نفس القواعد.

تشتغل على **GitHub Actions** (مجاناً، من الجوال، بدون كمبيوتر)، أو على أي كمبيوتر.

---

## الإعداد من الجوال (مرة واحدة، 10 دقائق تقريباً)

**1) سوِّ حساب GitHub**
افتح github.com من المتصفح وسجّل حساب جديد.

**2) أنشئ مستودع**
اضغط **+** ثم **New repository**:
- الاسم: `options-scanner`
- اختر **Public** (المسح المجدول مجاني بدون حد. الكود يكون ظاهر، لكن التوكن مخفي في الأسرار)
- فعّل **Add a README file**
- اضغط **Create repository**

**3) ارفع الملفات**
فك ضغط الملف في الجوال، ثم في صفحة المستودع اضغط **Add file ← Upload files** واختر هذي الخمسة:
`scanner.py` و`backtest.py` و`config.json` و`requirements.txt` و`README.md`
ثم اضغط **Commit changes**.

**4) أنشئ ملفي الجدولة** (ما ينرفعون كمجلد من الجوال، فننشئهم يدوياً)
- اضغط **Add file ← Create new file**.
- في خانة الاسم اكتب بالضبط: `.github/workflows/scan.yml`
- الصق محتوى ملف `scan.yml`، واضغط **Commit changes**.
- كرر نفس الخطوات باسم `.github/workflows/backtest.yml` ومحتوى `backtest.yml`.

**5) أضف أسرار تيليجرام**
**Settings ← Secrets and variables ← Actions ← New repository secret**:
- الاسم `TELEGRAM_BOT_TOKEN` والقيمة توكن البوت.
- الاسم `TELEGRAM_CHAT_ID` والقيمة رقمك من @userinfobot.

**6) جرّب**
- **Actions ← ماسح الأسهم ← Run workflow**: يمسح الحين ويرسل لك قائمة المرشحين.
- **Actions ← الاختبار التاريخي ← Run workflow**: يرسل لك تقرير نسبة النجاح خلال 10–30 دقيقة.

بعدها المسح يشتغل تلقائياً كل 15 دقيقة وقت السوق، والتنبيهات توصلك وجوالك مقفل.

> إذا ما وصلت رسالة: افتح التشغيل في **Actions**، ثم خطوة **المسح**، وانسخ الخطأ.

## وش تسوي الأداة

**1) تكتشف السهم المرشح** (تقييم من 100 وفوق):
| العامل | النقاط |
|---|---|
| انضغاط التذبذب (بولنجر داخل كلتنر، أو أضيق نطاق خلال 6 أشهر) | +25 |
| اختراق قمة أو كسر قاع 20 يوم | +30 |
| قريب من مستوى الاختراق (أقل من نصف ATR) | +10 |
| الحجم النسبي مقارنة بمعدل 20 يوم | حتى +25 |
| مدى اليوم أكبر من 1.5 ضعف ATR | +10 |
| الاتجاه (EMA20/EMA50) | +5 |
| أرباح خلال أسبوع | +15 |
| تدفق عقود داعم (كول/بوت) | +10 |
| نشاط عقود غير اعتيادي | +5 |

**2) ترشّح العقد الأسبوعي:** انتهاء 3–14 يوم (الأقرب لـ7)، دلتا قريبة من 0.40، اهتمام مفتوح 300 أو أكثر، حجم 50 أو أكثر، فارق bid/ask لا يتجاوز 15%، ونقطة تعادل داخل الحركة المتوقعة. ويقرأ شارت العقد بشكل مبسط (EMA9 وVWAP على فريم 15 دقيقة).

**3) التنبيهات:**
- 👀 **قائمة المرشحين:** مرة يومياً بعد الافتتاح، مع مستويات الدخول.
- 🚀/🔻 **إشارة دخول:** عند الاختراق بحجم 1.5 ضعف المعدل أو أكثر، مع العقد والهدف والإيقاف. مرة وحدة لكل سهم في اليوم.

## الاختبار التاريخي

يطبّق نفس قواعد إشارة الدخول على كل يوم في الفترة المحددة، ويطلع لك:
- نسبة تحرك السهم في الاتجاه الصح بعد 1 و3 و5 أيام، مقارنة بأي يوم عشوائي.
- نسبة وصول السهم لنقطة تعادل عقد دلتا 0.40 قبل الانتهاء.
- محاكاة صفقة العقد: نسبة الرابحة، متوسط العائد، متوسط الربح والخسارة، ومعامل الربح.
- تفصيل حسب الاتجاه، والانضغاط، ودرجة التقييم، والسنة.

**كيف تقرأ النتيجة:** أهم رقمين هم **متوسط العائد** و**معامل الربح**. نسبة رابحة 35% ممكن تكون ممتازة إذا معامل الربح فوق 1.3، ونسبة 60% ممكن تكون خاسرة إذا الخسائر كبيرة. وإذا كان "اتجاه 5 أيام" قريب من نسبة اليوم العشوائي، فالإشارة ما تضيف ميزة حقيقية.

**حدود الاختبار:**
- أسعار العقود التاريخية غير متوفرة مجاناً، فالعقد يُسعَّر بمعادلة بلاك-شولز (التذبذب التاريخي × 1.2).
- الدخول محسوب عند إغلاق يوم الإشارة.
- نقاط الأرباح وتدفق العقود غير داخلة، لأن بياناتها التاريخية غير متوفرة.

إعدادات المحاكاة موجودة في `config.json` تحت `backtest` (جني الربح، الوقف، معامل التذبذب).

## التشغيل على كمبيوتر (اختياري)

```
pip install -r requirements.txt
python scanner.py --test-telegram     # اختبار تيليجرام
python scanner.py                     # تشغيل مستمر وقت السوق
python scanner.py --once              # مسح واحد
python backtest.py --years 2          # اختبار تاريخي
python backtest.py --tickers NVDA TSLA AMD
```
على الكمبيوتر، حط التوكن والـ Id في `config.json`. على GitHub لا تحطهم في الملف، استخدم الأسرار.

## ملاحظات

- **البيانات من Yahoo Finance ومتأخرة حوالي 15 دقيقة.** تأكد من السعر في منصتك قبل التنفيذ.
- **توقيت GitHub قد يتأخر 5–15 دقيقة** في أوقات الضغط.
- **إيقاف تلقائي:** GitHub يوقف الجدولة في المستودعات العامة إذا مرت 60 يوم بدون أي تعديل، ويرسل لك إيميل قبلها. تقدر تعيد التفعيل بضغطة من صفحة Actions.
- **إيقاف المسح يدوياً:** **Actions ← ماسح الأسهم ← ⋯ ← Disable workflow**.
- **الأداة للفرز ومساعدتك في القرار، وليست توصية استثمارية.** العقود الأسبوعية ممكن تفقد قيمتها كاملة، فحدد حجم الصفقة والإيقاف دائماً.
